      What defeated us / limitations

      • A small docs budget: about 3K tokens of docs per app, which is what Groq's free 8K-tokens-per-minute limit allows. A fact in a paragraph that wasn't picked can be missed; the pre-scan reads full pages to catch some of these.
      • Free quotas capped the re-research. It ran on the most-flagged apps first until quota ran out. The rest are marked needs_human, not guessed.
      • Same-name products (e.g. "Sherlock") can pull in the wrong vendor's pages when the hint is only a GitHub repo.
      • Login-walled or JS-only docs can defeat httpx, Tavily extract and headless Chromium alike.
      • Provider churn while building: Mistral's free API and GitHub Models became unavailable, and so did Composio's free search toolkit. Composio friction we hit:
        • `toolkits.get()` returns at most 1,000 toolkits. The full catalogue (1,865) needs cursor paging through `client.toolkits.list(cursor=…)`.
        • `tools.get_raw_composio_tools(toolkits=["composio_search"])` returns `[]`, although the toolkit reports `tools_count=21`. The slugs only resolve one by one with `get_raw_composio_tool_by_slug`.
        • The docs page `docs.composio.dev/toolkits/composio_search` returns 404. The marketing page lists tool display names but no slugs.
        • **Every `COMPOSIO_SEARCH` tool returns HTTP 410:** "Toolkit COMPOSIO_SEARCH version … is retired and its tools can no longer be executed." This happens for the latest version (`20261119_00`), which `toolkits.get()` still lists as current, and for older pinned versions, through both `tools.execute` and sessions.
        • Toolkits marked `instant: supported` (Firecrawl, You.com) return 403 "Instant accounts are not enabled for …". The SDK docstring says the project must allow Instant usage, and Instant calls are charged.
